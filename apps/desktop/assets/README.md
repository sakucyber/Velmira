# Velmira CJK

The Regular face is a renamed subset of [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)
by Adobe, licensed under the SIL Open Font License. See [OFL.txt](OFL.txt).
The source variable font's SHA-256 is
`763146584cf0710223441356b4395e279021b0806c196614377a7a0174ae074a`.
The subset is instantiated at weight 400 with fontTools 4.68.0, retains
U+0020–02FF, U+2000–206F, U+3000–303F, U+3400–4DBF, U+4E00–9FFF and
U+FF00–FFEF where present, and uses the family name Velmira CJK.
