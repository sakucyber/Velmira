# M4 成页与 CBZ 验证

## 已实现

- 七种拼页模板：`1x1`、`2x1`、`2x2`、`2x3`、`3x2`、`1+2`、`2+1`，自动模板按格数选择。
- Pillow 后端合成，支持白边、圆角外框、完整显示／裁切、中文字体、旁白、对白、说话人、圆角／椭圆气泡和左右尾巴。
- 页编辑器支持添加、移除、前移、文字修改、模板和字号调整；修改使用 revision 乐观锁。
- 分镜源在保存和导出前重新校验；源图、人物形态、参考图或场景变化会使页面进入 stale，已发布的 CBZ 使用不可变图片。
- 页面可软删除与恢复；导出包含 `ComicInfo.xml` 和有序 PNG；重复导出复用完整归档，文件丢失或损坏时可修复且不会重复登记漫画书。
- 小说阅读器和漫画阅读器互相提供定位链接，进度分别按书籍保存。

## 自动验证

`tests/test_manga_pages.py` 新增 10 项，和现有测试合计 **100 项通过**。覆盖几何不重叠、中文文字溢出拒绝、跨书和未复核分镜拒绝、源变化回滚、revision 冲突、排序、删除／恢复、并发导出、20 页五章样例、CBZ 内容和重新导入。

`tests/cdp_manga.mjs` 覆盖桌面和 390px 手机：编辑旁白／对白、椭圆气泡、修改升版、重排、导出、漫画／小说双向切换、无横向溢出和无 JavaScript 异常。

Windows 自包含包已生成：`dist/Velmira-desktop-v0.4.0-m4`。桌面窗口通过 Computer Use 启动并检查，窗口标题为 Velmira，未出现命令行窗口。

## 样例与人工验收

`.tmp/m4-live` 中有一份原创中性五章样例：MOSS 实际生成 20 张图，拼成 20 页并导出 CBZ。样例图经过视觉检查，人物服装和日系二次元风格保持一致，旁白和对白后置可编辑。该目录被 `.gitignore` 忽略，不进入仓库。

本机人脸校验缺少 `cv2`，因此样例任务按安全规则先标记为 `needs_review`，再作为人工复核样例登记；没有把它们伪报成自动通过，也没有填写人工评分。M4 里程碑要求的“人工评分 ≥4/5”仍需实际评审者打开 CBZ 后给出分数。
