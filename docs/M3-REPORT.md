- `/api/books/{book_id}/manga/config` 保存 ComfyUI、模型、尺寸、采样、人脸阈值和校验器路径；`/probe` 检查节点与模型。
- 形态、章节/段落生效锚点和版本化参考图在 SQLite 中保存。参考图上传或生成后都必须人工确认，身份卡升版会使旧参考图和任务变为过期。
