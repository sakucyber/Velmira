# 离线与多设备同步（v0.5.2）

## Android 本机书库

Android APK 内置界面和仅监听 `127.0.0.1` 的本地书库服务。首次打开无需
服务器地址，可选择主题、字号和书架密度，也可直接跳过进入书架。点击
「导入文件」即可从手机导入 TXT、EPUB 或 CBZ，随后离线阅读、搜索、
保存进度、书签和批注，无需连接电脑或再次下载。

本机书库的数据保存在应用私有 SQLite 与文件目录，清除应用数据或卸载
应用会删除。书架和小说阅读器提供手机 AI 工作台；Java 代理可直接请求
已配置的文本、生图和搜索服务，无需电脑。调用这些服务需要手机联网，
已保存的文字结果、记忆和图片可在本机查看。整本自动漫画任务链仍由电脑
服务运行，本机独立书库不自动参与远程同步。
在「设置 → 连接电脑」可切换到电脑书库；两边分别保存，当前不会自动合并。

手机 AI 支持章节总结、人物与人格、六格漫画分镜、问答和生图。模型连接、
降级顺序、轮询/最少并发负载均衡、RPM/并发限制、提示词、长期记忆和联网
搜索均在设置中管理。默认文本为 `gpt-6-luna`，生图依次为
`agnes-image-2.5-flash`、`agnes-image-2.1-flash`、`agnes-image-2.0-flash`。
APK 不含密钥，默认模型池关闭；首次需填写自己的密钥并启用。

## 连接同一服务的多设备使用

以下步骤适用于浏览器客户端，以及 Android APK 中可选的电脑连接模式：

1. 启动电脑 Velmira 服务并导入 TXT、EPUB 或 CBZ。手机首次连接时，先在服务
   本机的「设置 → 局域网访问」生成配对码，然后在手机完成配对。
2. 每台设备打开「设置 → 离线与同步」，点击书籍的「下载到本设备」，等待
   显示「已下载」。下载包括全部章节及安全内嵌图片，或 CBZ 全部图片页。
3. 断网后重新打开同一个服务地址，继续阅读、全文检索已缓存章节、保存进度、
   增删书签和编辑批注。未下载章节无法在断网时读取。
4. 回网后自动同步，或点击「立即同步」。自动同步可在同一设置页关闭。
   后台定时器仅在应用前台运行，关闭应用后不会持续同步。

## 支持范围

| 平台 | 运行方式 | 断网启动条件 |
| --- | --- | --- |
| Windows | 原有桌面包，或浏览器 | 桌面本地服务可离线运行；浏览器需先缓存界面 |
| Android | 内置 Java 本地书库服务 + 系统 WebView | 本机导入即可离线使用；可选电脑连接模式需先配对并下载对应远端书籍 |
| Linux / macOS | Python 服务 + 浏览器 | 本机 localhost，或通过 HTTPS 缓存界面的远程客户端 |
| iPhone / iPad | 支持 IndexedDB / Service Worker 的浏览器 | HTTPS、成功缓存界面及下载；本轮没有原生 IPA，也未做真机验收 |

普通浏览器在局域网 HTTP 地址上通常不能安装 Service Worker，因此不能保证
服务关机后的重新启动。Android APK 内置静态界面和本地阅读服务，不依赖
该能力。首次安装后可直接导入手机文件。APK 没有捆绑书籍或本地推理模型，
手机 AI 通过内置 Java 代理调用用户配置的云端模型。

Windows Edge 的断网重载、阅读、图片、编辑与回网同步检查，以及各平台的
设备验证范围，见 [OFFLINE-VALIDATION.md](OFFLINE-VALIDATION.md)。
Linux / macOS 复用相同的服务及前端代码，仍需各自设备验证系统级行为。

## 同步与冲突

本节描述连接同一电脑服务的远端同步，不包含 Android 本机独立书库。
同步对象是阅读进度、书签和批注。各设备显式下载正文和图片；长期记忆、
模型设置、API Key、AI 生成任务不在当前远程同步范围内。所有设备连接
同一服务才会汇合数据，当前没有内置公共云或跨服务账号系统。
手机自己的模型设置、记忆与 AI 历史也仅保存在当前设备，和电脑服务的
配置分别管理。

操作保存在设备 IndexedDB，服务端使用操作 ID 去重和增量游标。批注修改
发生版本冲突时，离线内容保留在「待处理冲突」中，可以复制内容，选择
「保留本机版本」或「采用服务器版本」，再同步。相同位置的重复书签可采用
已有书签。阅读进度按事件时间合并，设备系统时钟应正常。

服务本机可撤销已注册设备，同时终止关联配对会话。撤销不远程擦除设备上
已下载的内容。重新授权时先配对，再在离线设置中重新注册设备；待同步操作
会迁移到新身份。

## 存储与清理

Android 本机导入的书籍与阅读记录保存在应用私有 SQLite，源文件和图片在
私有文件目录。本地导入单文件上限 64 MB，EPUB / CBZ 解压内容上限 512 MB，
单图上限 32 MB，CBZ 最多 2000 页。

手机 AI 配置、密钥、记忆和历史保存在设备私有配置中，并排除 Android
云备份与设备迁移；生成图片保存在应用私有文件目录。密钥不会返回到 WebView。
卸载或清除应用数据会一并删除这些本机内容。

连接电脑服务时，设备下载的正文与阅读记录保存在 `velmira-local` IndexedDB，图片在 `velmira-media`。
Service Worker CacheStorage 只保存静态界面。不同服务地址、浏览器配置文件
和应用分别隔离；IP 或端口变化会被视为不同来源，原缓存不会自动迁移。
如果在同一个地址重建了整个服务数据库，应清理旧下载并重新下载书籍。

设置中的「清除本机下载」删除本设备对应正文、图片和阅读缓存，服务端保留
原书。有未同步修改时拒绝清除。卸载应用、清除浏览器站点数据或系统回收
存储可能移除本机副本，包括尚未同步的操作；需要长期保存时应完成同步。

下载会请求浏览器持久存储授权，但系统是否保留由平台决定。当前每张图片
上限 32 MB，每次书籍图片下载上限 512 MB，CBZ 上限 2000 页。配额不足或
下载中断不会标为完整下载，可重新下载。

```text
python -m pytest -q

node tests/cdp_offline.mjs
node tests/cdp_offline_media.mjs
```

模型，不修改用户书库。API 格式见 [API-CONTRACT.md](API-CONTRACT.md)。
