# 自动漫画与同步阅读

在阅读页打开“自动漫画”，选择文本模型和图像后端。完成章节分析后，文本模型先按剧情分页，再把每页连续原句分组到画格。每页为 1–7 格，同一章节可生成多页，短场景可只生成一格。原句组按顺序覆盖本页正文；跳句、重叠或错误引用会触发纠正重试。分页、分镜、生成图片和拼页进度分别保存，暂停后可继续。

默认画风为日系二维彩色漫画。提示词由以下内容组成：二维漫画媒介、冻结的人物外观及参考图、原文支持的动作和表情、场景与道具、光线、镜头和构图、线稿与上色要求。基调为 `Japanese anime-style full-color manga panel, clearly hand-drawn 2D illustration, clean precise ink linework, expressive anime eyes, stylized facial features, refined cel shading, soft color gradients, layered illustrated hair highlights, cohesive color palette`。默认排除摄影、真人、真实皮肤毛孔、超写实和 3D 渲染，以及低清晰度、肢体错误和水印。动作和场景随原文生成，参考图片里的剧情及文字不会作为指令加入小说。

每格先生成没有文字的单幅图，再由程序排入漫画页并添加中文旁白和对白。这样可选择 5 格、7 格等不等列排版，也可直接用单格图同步阅读。双人同框需要支持多参考图的图像 API；当前 MOSS 模板仅支持单人参考。明确选择其他画风或自定义提示词时，保留该选择。

阅读页在宽屏左侧显示小说、右侧显示本章漫画，窄屏上下排列。底部提供三种模式，切换时沿用同一个原文位置：

- 手动：滚动或翻页时定位对应画格；点击画格可跳到相应原文。
- 自动播放：按速度连续推进正文，并在进入下一格原文范围时切换漫画；支持暂停、继续、调速和跨章。
- 语音朗读：连续朗读原文，按浏览器的语音位置回调定位正文并切换画格；支持暂停、继续和调速。语音、可用语言及位置回调精度取决于浏览器和系统语音服务；没有逐字回调时按朗读片段结束推进。

每格记录章节及 Unicode 字符半开范围 `[start,end)`，表情符号与换行也按同一规则定位。原文改变、引用无效或图片缺失时不使用该映射。旧图若没有可信来源范围，需要重新编排生成后才能参与同步。

每章另存 100–250 token 的语义记忆，并归档带原文位置的事件、关系、物品、悬念和状态事实。分镜只接收预算内且发生在当前位置之前的历史，防止本章结局或变身后的外貌出现在早期画格。已知模型使用相应 tiktoken 编码；未知编码明确标记估计。具体设计与 DSH 参考见 [章节记忆](CHAPTER-MEMORY.md)。
